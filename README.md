## What I do

- **Web development:** custom, high-performance sites and apps with React and Next.js, plus Python backends.
- **AI / computer vision:** CNN-based image processing. It's the field I'm specializing in.
- **Search visibility (SEO + GEO + AEO):** I design sites so that they get found by search engines *and* cited by AI answer engines.

## Search visibility: how I approach it

| Layer | Goal | What I work on |
|---|---|---|
| **SEO** | Rank in classic search | Technical SEO, semantic HTML, metadata, sitemaps, Core Web Vitals, internal linking |
| **AEO** | Win direct answers / featured snippets | Question-led content structure, concise answer blocks, FAQ and HowTo structured data |
| **GEO** | Get cited by AI assistants (ChatGPT, Gemini, Perplexity…) | Clear entity definitions, JSON-LD schema, crawlable content, `llms.txt`, authoritative and quotable copy |
